# 얼굴무늬 수막새 · 천년의 미소

사용자가 제공한 GLB와 3개 질감 이미지로 추가한 3D·AR 전시입니다.

- 페이지: `https://qkfmsclzls22-sudo.github.io/silla-ar/smile/`
- 모델: `../smile-textured-v1.glb`
- 목록: 기존 루트 페이지에 카드 1개 추가. 다른 유물 페이지·모델은 변경하지 않음.

## 적용 내용

원본 GLB에는 TEXCOORD_0가 없고 흰색 vertex color 2개와 회색 재질만 있었습니다. 원본 얼굴 형상 544,681개 삼각형을 유지하고, 앞면의 주요 위치를 기준으로 투영 UV를 재구성했습니다. 뒷면과 파손면은 공급된 텍스처의 표면 영역을 사용합니다. 이는 원본 스캔의 UV를 복원한 것이 아니며, 특히 파손면과 코 주변의 정확한 질감 위치는 원본 UV가 있는 모델보다 제한됩니다.

- `_C`: base color. 원본 색상 이미지 내장.
- `_N`: normal map. 재구성 UV의 과장된 요철을 줄이기 위해 강도 0.18.
- `_P`: 채널 분포상 R=AO/G=roughness/B=metallic로 추정하여 적용. 원본 제작 설정은 제공되지 않았으므로 확정 정보가 아님. 흙 재질에 맞춰 metallicFactor=0 고정, AO 강도 0.25.
- 정면에서 미소가 보이는 방향으로 회전·중심 조정.
- 표시 높이 25cm로 정규화. 실물 측정 치수로 인증된 값이 아님.
- tangent를 명시적으로 생성해 브라우저별 normal map 차이를 줄임.
- Draco 압축: 최종 3,563,496 bytes (약 3.56MB). 원본 업로드 약 16.34MB.

## AR와 검증

`model-viewer@3.5.0` 및 기존 AR 버튼/카카오톡 안내 흐름 유지. `scene-viewer quick-look webxr` 사용. 이전 유물 USDZ를 연결하지 않고 현재 GLB에서 iOS용 USDZ를 자동 생성합니다.

- 압축 전 glTF validator: 오류 0, 경고 0.
- 최종 압축 GLB validator: 오류 0, 경고 0. 압축 확장을 validator가 직접 해석하지 못한다는 info가 있으므로 실제 브라우저에서 별도로 로드 확인.
- 실제 model-viewer 브라우저 로드: loaded=true, 재질 3개.
- front.png/back.png는 실제 3D 렌더이며 생성 이미지가 아님. 테스트 환경에서는 외부 CDN 스크립트와 한글 폰트를 동일/대체 로컬 자산으로 제공.
- iOS 자동 USDZ 생성 확인: 48,243,815 bytes, ZIP magic 정상. GLB 다운로드보다 iOS AR 변환·메모리 비용이 큼.
- 390px 모바일 가로 넘침 없음. AR 미지원 데스크톱에서 브라우저 안내 노출 확인.
- 실기기 카메라 공간 배치까지 테스트한 것은 아님. iPhone Safari / Android Chrome에서 확인 필요.

원본 업로드 파일은 변경하지 않았습니다. 질감 좌표의 완전한 일치가 필요하면 TEXCOORD_0를 포함한 원본 GLB/FBX로 교체해야 합니다.

## 추가 원본 점검 및 업로드

사용자가 지정한 Windows `04_Final_02` 폴더는 이 작업 환경에 연결되어 있지 않습니다. 따라서 해당 폴더를 읽거나 거기서 새로 변환했다고 간주하지 않습니다. 앞서 첨부된 전체 수막새 GLB와 동일한 질감 파일을 기준으로 준비된 위 완성본을 사용합니다. 원본 4개 파일의 SHA-256을 기존 기록과 다시 대조했습니다.

다른 첨부 FBX도 직접 파싱해 구분했습니다.

- `SM_24HO0001_01_High.fbx`: Geometry/Model 오브젝트가 없는 빈 장면입니다.
- `SM_24HO0001_04_Low.fbx` 및 동명 사본: 정점 400개, UV 좌표는 있으나 전체 수막새 모델과 범위가 다른 축소 데이터입니다. 전체 모델 대체에 사용하지 않았습니다.
- `SM_24HO0001_02_High.fbx`: 정점 2,723,422개의 전체 형상이 있으나 LayerElementUV가 없습니다. 이 파일로도 원본 질감 좌표를 복구할 수 없습니다.

현재 배포 GLB는 위에 기술된 기존 질감 재구성본입니다. 원본 UV를 보존한 변환본이 아닙니다. 파일 무결성·내장 이미지·페이지 모델 경로의 추가 점검 결과는 `deployment-verification.json`에 기록합니다. 공개 페이지의 실제 로딩 및 버튼 동작 검증과 실기기 카메라 AR 검증은 구분합니다.
