# 착용 AR 시범판 01
2026-09-14. 사용자 승인 전의 별도 실험 화면: /tryon-preview/ . 기존 /crown/, /smile/ 공간 AR 버튼 및 GLB는 변경하지 않음.
메인: 선덕여왕 카드만 숨김(파일 유지), 네 유물 카드를 실제 촬영 사진으로 교체. 다라니경은 허용된 전시 복제품 사진이며 카드와 사진 출처 페이지에 구분 표기.
## 구현
카메라 먼저 → 사용자 버튼으로만 유물 표시 → 촬영·저장/지원 기기 공유. 후면 기본, 전면 전환, 끄기·재시작.
MediaPipe Tasks Vision 0.10.21 얼굴 랜드마크와 회전 행렬, 단일 얼굴, 워커 기반 최대 약 12fps 인식. Three.js 0.160.1은 렌더링과 GLB 로딩. 640px 폭 감지 입력, DPR 최대 1.5. 기존 GLB 그대로 사용(금관 약 12.2MB/44만 삼각형, 수막새 약 3.6MB/54만 삼각형) — 저사양 폰 최적화는 후속 검토.
위치·크기·회전 보간, 1.4초까지 마지막 인식 위치를 잠시 유지. 이후 숨기고 재인식 시 복귀. 숨긴 상태에서는 사진 촬영 비활성화.
화면 고정은 명시적 수동 모드이며 얼굴을 추적하지 않음. 좌우/높이/크기/각도 및 드래그.
영상은 서버로 업로드하지 않음. JS/WASM/얼굴 모델은 jsDelivr 및 Google Storage에서 다운로드. 사진 공유는 사용자 동작시에만 OS 공유창 사용.
## 남은 한계
사진 기준의 화면 좌표에 얼굴 회전을 적용한 시범 합성으로, 실측 착용이나 완전한 원근 보정이 아님.
머리카락/머리의 가림, 여러 사람 얼굴 선택, 어두운 환경/빠른 움직임 개선은 후속 작업. 휴대폰 실물 테스트는 별도로 필요.
파일 검증 / 자동화 브라우저 검증 / 휴대폰 실기기 검증을 구분해 validation.json에 기록.
