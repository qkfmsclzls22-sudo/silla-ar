# Earring prototype v1

Original procedural Silla-inspired ornament, not an official artifact scan or exact reconstruction. Single earring, 82.8 mm nominal height. Gold PBR material. 322724-byte GLB, 7209 vertices, 12384 triangles. No external textures.

Independent /earring/ test page; existing home and artifact pages unchanged. Uses a dedicated copy of the existing foreground camera code with front camera default, smaller size range (8–180), initial size 30 and ear-oriented placement. Manual positioning, no face tracking or occlusion.

Validation: actual GLB rendered using model-viewer 3.5.0 in Chromium with fake camera; screenshots inspected (gold rings and hanging leaves visible). Capture JPEG 1170×1560; save/retake controls visible; retake starts camera again. Move after closing rotation panel works; touch drag changes position. 320×568 shutter fits viewport. No page errors. Fake camera produces green test pattern; no real portrait used. Physical iPhone Photos save and native AR not tested.

Generator and browser check script included for reproducibility. No previous earring model exists for before/after comparison.
