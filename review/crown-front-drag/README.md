# 금관 정면 기본값과 유물 자유 이동

## 변경
- 금관 카메라 기본 각도를 10deg 78deg 105% → 0deg 90deg 105%로 변경했습니다. 정면에서 수평으로 보이며 소개 화면 자동 회전도 해제했습니다. 모델 파일과 네이티브 AR 옵션은 보존했습니다.
- 처음 촬영을 열 때와 초기화할 때 기본 방향으로 맞춥니다. 촬영 창을 닫았다 다시 열어도 금관 정면으로 시작합니다.
- 금관·토우·수막새 공통 촬영 화면에서 중심 좌표를 0~100%로 제한하던 처리를 제거했습니다. 화면 가장자리 밖으로도 드래그할 수 있습니다.
- 유물 맞추기 패널을 닫으면 조절한 방향을 유지하면서 위치 이동 모드로 돌아갑니다. 초기화로 화면 가운데/기본 크기/기본 방향을 복구할 수 있습니다.

## 실제 브라우저 확인
Chromium 모바일 390×844, 실제 crown_side_ornaments_v4.glb와 가상 카메라를 사용했습니다. before.jpg / front.jpg / capture.jpg는 실제 페이지의 전후 및 촬영 결과입니다. 녹색 배경은 테스트 카메라 영상입니다.

- 기본/초기화/촬영 재진입 모두 yaw 0°, polar 90°.
- 회전 조절 후 패널을 닫아도 yaw 25°, polar 80° 유지. 이동 모드로 전환됨.
- 실제 터치 드래그로 중심 좌표 x/y=110%, -10%까지 이동해 기존 경계 제한 제거를 확인.
- 초기화 후 x/y=50%, 정면 방향 복구.
- 합성 사진 생성, 저장/다시 찍기 표시, 재촬영 확인. 브라우저 오류 0건.
- 실제 iPhone 화면과 Photos 앱 저장은 직접 검증하지 않았습니다.

상세 결과는 check.json에 기록했습니다.
