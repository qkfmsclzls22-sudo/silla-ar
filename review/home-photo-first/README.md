# 메인 체험 순서 변경 · 2026-10-13

- 유물 사진 체험을 웹체험보다 앞에 배치했습니다. 금관 → 토우 → 수막새 → 불상의 미소 순서입니다.
- 무구정광대다라니경 카드는 메인에서 임시 제외했습니다. 기존 체험 파일은 유지합니다.
- 불상은 기존 창작 얼굴 이미지와 개선된 play/photo.html?v=camera2로 연결합니다.
- Chromium 390×844 / 1440×1000 실제 브라우저에서 새 HTML/CSS를 적용해 비교했습니다. 모바일 사진 영역 제목 y=1649→196px, 웹체험 제목 y=223→1041px. 데스크톱에서도 사진 영역이 먼저 보입니다.
- 모바일 2열 / 데스크톱 4열 카드, 가로 넘침 없음, 사진 카드 4개, 다라니경 카드 없음, 이미지 7개 로딩 성공을 확인했습니다.
- 불상 카드 클릭 후 실제 공개 촬영 페이지의 사진 찍기 버튼까지 연결을 확인했습니다. 이번 변경은 메인 구성에 한정하며 카메라/AR 구현을 변경하지 않습니다.
