# 불상 포토 카메라 화면 개선 · 2026-10-13

## 변경
- 사진 찍기 → 카메라 권한 허용 → 불상 얼굴이 즉시 표시됩니다. 별도 얼굴 띄우기 단계는 없습니다.
- 촬영 화면 안의 흰색 원형 버튼으로 촬영하며, 결과 화면에 사진첩에 저장 / 다시 찍기가 즉시 표시됩니다.
- 촬영, 조절, 저장, 재촬영은 뷰포트 안에서 진행합니다. safe-area와 visualViewport 높이를 반영합니다.
- 파일 공유를 지원하면 준비된 PNG를 사용자 탭 안에서 네이티브 공유 메뉴에 전달합니다. 아이폰에서는 이미지 저장을 선택합니다. 지원하지 않거나 공유 오류가 발생하면 다운로드 / 이미지 길게 누르기 안내를 제공합니다. 공유 취소를 저장 완료로 표시하지 않습니다.
- 촬영하면 카메라를 중지하고 사진을 유지합니다. 다시 찍기를 누르면 카메라를 재시작합니다. 다른 앱이나 저장 메뉴로 이동해도 촬영 사진을 지우지 않습니다.

## 실제 브라우저 비교
- before.jpg: 기존 Chromium 모바일 화면. 높이 844px에서 촬영 버튼은 y=923~967px, 전체 페이지 높이 1067px로 스크롤이 필요했습니다.
- live.jpg: 변경 후 흰색 원형 셔터와 자동 표시된 얼굴.
- review.jpg: 변경 후 촬영 결과 및 저장 / 다시 찍기.
- 녹색 배경은 Chromium의 가상 카메라 테스트 영상입니다. 실제 인물 촬영 또는 AI 생성 화면이 아닙니다.

## 검증 범위
- Chromium 실제 페이지 + 가상 카메라로 390×844, 375×667, 320×568, 844×390에서 시작 / 촬영 / 조정 / 결과 / 다운로드 / 재촬영을 확인했습니다. 모든 상태의 페이지 높이가 화면 높이 이내이고 핵심 버튼이 화면 안에 위치합니다.
- PNG 다운로드 파일 생성(900×1200), 두 손가락 확대, 가운데 맞추기, 좌우 반전, 카메라 전환, 권한 거절, 백그라운드 중지/복귀를 확인했습니다.
- 네이티브 공유 API는 스텁으로 호출 시 사용자 활성화와 PNG File 전달, 취소, 오류 후 대체 저장 동작을 확인했습니다. iOS Photos 앱의 실제 저장은 실기기에서 검증하지 않았습니다.
- 브라우저 오류 0건. 상세 실행 결과는 viewport-checks.json / interaction-checks.json에 기록합니다.

## 변경 범위
photo.html, photo.js, 전용 photo-camera-v2.css, 해당 포토체험 안내 문구 및 링크, 이 검토 자료만 수정했습니다.
