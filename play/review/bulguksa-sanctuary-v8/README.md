# 불국사 메타버스 소원마당 v8 — 2026-11-23

미리보기 경로: `/play/?tour=bulguksa&mode=sanctuary`
기본 경로(`/play/?tour=bulguksa`, 사진 소원마당 v7)와 classic 경로는 그대로다. 박물관·월성·AR 포토 자산은 건드리지 않았다.

## 추가한 것
- `sanctuary-scene-v8.js`: 대웅전·석가탑·다보탑·회랑·자하문·석등·방석 10개·연등 줄 3개(40자리)를 절차적으로 만든 3D 마당. 실측 복원이 아닌 단순화 모형.
- 아바타(동자승/여행자): 바닥을 누르면 걸어가고 카메라가 따라간다. 빠른 이동 버튼 4개.
- 참배: 합장, 절(1배·삼배·21배·108배 카운터, 수동/자동), 목탁(WebAudio 합성음·진동), 고요히 앉기(타이머·종소리).
- 연등: 색과 소원(40자), 한 사람에 하나, 읽기·고치기·내리기. 밤으로 바꾸면 점등.
- 일행 모드(`&room=`): 기존 PeerJS 방식 재사용, 최대 10명. 아바타 위치·동작·연등 공유. 대화 기능 없음.
- 기념카드: 현재 장면 + 오늘의 절·목탁·앉은 시간·소원을 1080×1440 PNG로 저장.

## 실제 브라우저(Chromium, 소프트웨어 WebGL)로 확인한 것
- 390×844, 1280×800에서 페이지 오류 없음.
- 입장 → 삼배(기록 3배) → 목탁 2회 → 연등 달기(로컬 저장) → 밤 전환 → 앉기 → 21배 모드 카운터 → 기념카드 생성.
- 일행 3명 동시 접속: 인원 표시 3명, 다른 사람의 절 동작과 연등이 보이는 것을 화면으로 확인.

## 확인하지 못한 것 (한계)
- 일행 접속 테스트는 PeerJS 서버 대신 **모의 전송 계층**으로 했다. 작업 환경에서 실제 PeerJS 서버에 접속할 수 없었다. 실제 망에서의 연결은 미검증.
- 실제 iOS/Android 기기의 터치·핀치·진동·소리·성능은 미검증.
- 10명 동시 접속 미검증(3명까지 확인).
- 혼자 모드의 기록과 연등은 해당 브라우저에만 저장된다. 일행 마당은 처음 연 폰이 호스트이며 그 폰이 꺼지면 끊긴다(기존 방식의 제약 그대로).

- 이전 목탁 소리는 녹음 없이 사인파 4개(540·815·1390·270Hz)와 3.5ms 잡음을 더해 계산한 소리였다. 나무를 칠 때 나는 넓은 대역의 "딱" 하는 타격음과 속 빈 몸통의 짧은 울림이 없어 전자음처럼 들렸다.

## 바뀐 것
- 실제 나무 타악기를 한 번 친 녹음을 바탕으로 바꿨다. FluidR3 GM 사운드폰트의 Woodblock 음색(CC BY 3.0, gleitz/midi-js-soundfonts 변환본)에서 한 음(56번)을 골라 0.36초로 자르고 22.05kHz 16비트로 줄여 `play/sanctuary-sounds-v8.js` 안에 넣었다(약 21KB). 출처와 처리 과정은 `play/assets/bulguksa-v8/sound-provenance.json`, 사이트 출처 페이지(`about.html`)에도 적었다.
- 목탁(기본: 통통 울리는 소리)은 녹음의 가장 낮은 울림(약 640Hz)에 맞춘 공명을 더해 속 빈 몸통 소리를 살리고, 딱딱한 채 소리를 조금 누그러뜨렸다. 길이 약 0.56초, 200ms 뒤 -43dB.
- 같은 모듈에 후보 두 가지를 더 남겼다: 녹음 그대로의 또렷한 소리(`clear`), 0.78배 낮춘 큰 목탁 소리(`big`). `sanctuary-v8.js`의 `MOKTAK_KIND` 한 곳만 바꾸면 된다.
- 목어(좌경루)도 같은 녹음을 0.46배로 낮고 길게 늘인 나무 소리로 바꿨다. 법고·운판·종은 그대로.
- 칠 때마다 똑같은 소리가 반복되지 않도록 목탁·목어는 음높이(±1.4%)와 세기(최대 -12%)를 조금씩 바꾼다. 아이폰 방식(<audio> 태그)에서는 음높이를 미리 달리한 파일 4개를 번갈아 쓴다.

## 확인한 것
- Node에서 실제 배포 모듈로 소리를 그려 스펙트럼과 감쇠를 측정(위 수치), 값이 모두 유한하고 최대값 0.97.
- Chromium(390×844)에서 목탁 버튼을 6번 눌러 일반 방식(Web Audio)으로 6번 재생, 재생 속도가 매번 다른 것 확인. 아이폰 사용자 에이전트로 <audio> 태그 방식에서 목탁 4개(0.55~0.57초)·목어 2개(1.08~1.10초) 파일이 만들어지고 번갈아 재생되는 것 확인. 두 방식 모두 페이지 오류 없음.

## 확인하지 못한 것 (한계)
- 실제 스피커로 들어 보지는 못했다. 미리듣기 페이지로 사용자가 직접 들어 보고 고르도록 했다.
- 실제 불국사 목탁을 녹음한 소리가 아니다. 공유마당에 김용배 님의 목탁 녹음(CC BY 4.0)이 있지만, 내려받으려면 설문을 거쳐야 하고 사용자 컴퓨터로 받아야 해서 이번에는 쓰지 않았다.
