# 불국사 메타버스 소원마당 v8 — 2026-11-23

미리보기 경로: `/play/?tour=bulguksa&mode=sanctuary`
기본 경로(`/play/?tour=bulguksa`, 사진 소원마당 v7)와 classic 경로는 그대로다. 박물관·월성·AR 포토 자산은 건드리지 않았다.

## 추가한 것
- `sanctuary-scene-v8.js`: 대웅전·석가탑·다보탑·회랑·자하문·석등·방석 10개·연등 줄 3개(40자리)를 절차적으로 만든 3D 마당. 실측 복원이 아닌 단순화 모형.
- 아바타(동자승/여행자): 바닥을 누르면 걸어가고 카메라가 따라간다. 빠른 이동 버튼 4개.
- 참배: 합장, 절(1배·삼배·21배·108배 카운터, 수동/자동), 목탁(WebAudio 합성음·진동), 고요히 앉기(타이머·종소리).
- 연등: 색과 소원(40자), 한 사람에 하나, 읽기·고치기·내리기. 밤으로 바꾸면 점등.
- 일행 모드(`&room=`): 기존 PeerJS 방식 재사용, 최대 10명. 아바타 위치·동작·연등 공유. 대화 기능 없음.
- 기념카드: 현재 장면 + 오늘의 절·목탁·앉은 시간·소원을 1080×1440 PNG로 저장.

## 실제 브라우저(Chromium, 소프트웨어 WebGL)로 확인한 것
- 390×844, 1280×800에서 페이지 오류 없음.
- 입장 → 삼배(기록 3배) → 목탁 2회 → 연등 달기(로컬 저장) → 밤 전환 → 앉기 → 21배 모드 카운터 → 기념카드 생성.
- 일행 3명 동시 접속: 인원 표시 3명, 다른 사람의 절 동작과 연등이 보이는 것을 화면으로 확인.

## 확인하지 못한 것 (한계)
- 일행 접속 테스트는 PeerJS 서버 대신 **모의 전송 계층**으로 했다. 작업 환경에서 실제 PeerJS 서버에 접속할 수 없었다. 실제 망에서의 연결은 미검증.
- 실제 iOS/Android 기기의 터치·핀치·진동·소리·성능은 미검증.
- 10명 동시 접속 미검증(3명까지 확인).
- 혼자 모드의 기록과 연등은 해당 브라우저에만 저장된다. 일행 마당은 처음 연 폰이 호스트이며 그 폰이 꺼지면 끊긴다(기존 방식의 제약 그대로).

# rev.2 — 2026-11-23 (같은 날 2차 보완)

사용자 요청: 불국사 느낌 강화, 대웅전 법당 안에서 절하기, 합장이 실제 동작으로 보이기, 연등 불빛과 소원 글씨, 선 자리에서 바로 절하기, 목탁 그림과 소리, 국가유산청 3D 데이터 활용, 목어·운판·법고 쳐 보기.
경로는 그대로 `/play/?tour=bulguksa&mode=sanctuary`. 기본 불국사 화면(v7)과 다른 투어는 건드리지 않았다.

## 바뀐 것
- 공간: 아래 광장 → 청운교·백운교(석축, 난간) → 자하문 → 마당 → 대웅전 법당 안까지 높낮이가 있는 한 공간으로 다시 만들었다. 단청 띠, 용마루, 단풍나무 추가. 구역(광장/계단/마당/법당)마다 길을 이어 걷고, 탑과 석등은 돌아서 간다.
- 대웅전 법당 안: 바닥을 누르면 걸어 들어간다. 안에 있으면 겉벽과 지붕은 그리지 않고(그림자는 유지) 안쪽 벽·천장·불단·후불탱화·촛불·천장 연등·방석 10개를 그린다.
- 국가유산청 3D 데이터 2종 사용(공공누리 제1유형, 출처표시):
  - 법당 가운데 불상: 기존 저장소의 `assets/museum-v4/amitabha-v1.glb`(경주 불국사 금동아미타여래좌상)를 재사용. 실제로는 극락전 불상임을 안내문에 적었다.
  - 다보탑: 공공데이터포털 「국가유산청_경주 불국사 다보탑 3D 모델링_20241231」 OBJ(1,071만 면, 8192 텍스처, zip 279MB)를 `assets/bulguksa-v8/dabotap-khs-v1.glb`(약 11만 면, 2048 텍스처, 1.18MB)로 줄였다. 가공 내역은 `assets/bulguksa-v8/dabotap-provenance.json`. 형태를 새로 만들거나 고치지 않았고 주변 땅만 잘라 냈다.
  - 석가탑, 대웅전, 자하문, 범영루·좌경루, 청운교·백운교는 공개 3D 파일을 찾지 못해 직접 만든 단순화 모형이다.
- 아바타: 팔(2관절 IK)·다리 관절을 넣어 합장(반배 포함), 큰절(무릎 꿇고 엎드림), 가부좌, 목탁 치기, 사물 치기를 실제 동작으로 보여 준다. 동작할 때 카메라가 잠깐 옆·앞으로 돈다.
- 절: 선 자리에서 바로 한다(마당에서는 불단 쪽을 본다). 법당 방석으로 가서 하는 선택지도 남겼다.
- 목탁: 아이콘을 목탁 그림(SVG)으로 바꿨다. 소리는 미리 계산한 파형으로 더 크고 또렷하게 냈다. iOS는 무음 스위치가 Web Audio를 막아서 `<audio>` 재생 + `navigator.audioSession.type='playback'`을 쓴다.
- 불전사물: 범영루에 법고, 좌경루에 목어·운판(실제 불국사 배치). 누르면 다가가서 치고, 악기가 흔들리며 소리가 난다. 각 악기의 뜻을 짧게 안내한다.
- 연등: 달면 낮에도 색과 불빛(후광, 바닥 빛)이 보이고, 등 아래에 소원 글씨(세로쓰기)와 이름이 달린 꼬리표가 붙는다. 달고 나면 카메라가 내 연등을 비춘다.
- 일행 모드: 새 동작(목탁·법고·목어·운판)과 넓어진 이동 범위를 규칙에 추가. 예전 버전과 섞이지 않도록 방 식별자 접두어를 `gjtrip-sanctuary-v8b-`로 바꿨다. 연결 대기 시간을 18초에서 30초로 늘리고 첫 화면이 그려진 뒤 연결한다.
- 가볍게: 지붕 마루 조각과 연등 꽃잎을 한 덩어리로 합쳐 장면 개체 수를 2,693개에서 1,441개로 줄였다.

## 실제 브라우저(Chromium, 소프트웨어 WebGL)로 확인한 것
- 390×844에서 입장 → 청운교·백운교 오르기 → 마당 → 합장 → 제자리 큰절 → 목탁 → 법고·목어·운판 치기 → 다보탑·석가탑 → 법당 안 삼배(기록 3배) → 앉기 → 연등 달기(꼬리표 글씨 확인) → 밤 전환 → 전체 보기. 페이지 오류 없음.
- 대웅전 바닥을 눌러 법당 안으로 들어가기, 법고를 직접 눌러 치기, 21배 모드 카운터(수동 1회 + 자동 2회), 안내·절 메뉴·기념카드 화면, 1280×800 첫 화면.
- 일행 3명 동시 접속(모의 전송 계층): 인원 표시 3명, 다른 사람의 법고 치기·법당 안 삼배·목탁·연등이 서로 보이는 것을 상태값으로 확인. 오류 없음.
- 찾아서 고친 문제: 가운데 길을 걷다 석등에 걸려 제자리걸음 하던 것(돌아가는 길 + 걸림 감지 추가), 연등 확대 화면이 너무 가까웠던 것, 법당 천장 연등이 카메라를 가리던 것.
