# 월성 쌓기·수성하기 v9

주소: `play/?tour=wolseong&mode=fortress` (기존 `play/?tour=wolseong` 3D 꾸미기는 그대로)

## 바뀐 점
- 조작: 블록 고르고 땅을 콕(쌓기), 쭉 긋기(한 줄로 쌓기), 같은 자리 다시 누르기(한 층 더, 최대 3층). 두 손가락으로 돌리기·확대, ⟲ ⟳ ＋ － ⌂ 버튼. 기존의 놓기/옮기기/방향/둘러보기/화면 이동 도구 전환을 없앰.
- 월성 복원 설계도: 반달 언덕 가장자리 토성(북·동·서 2층, 남쪽 1층), 북쪽 해자, 성문 세 곳. 노란 칸을 누르면 설계도대로 쌓인다.
- 수성하기: 북·동·서쪽에서 침입군(창병, 사다리병, 기마병, 충차, 5레벨마다 적장). 남쪽은 남천이 막는다. 레벨마다 버틸 시간 60초 + 15초, 적 수·체력 증가, 재료 +40.
- 전투 뒤 부서진 성은 원래대로 복구(아이들이 만든 성을 잃지 않게). 적을 물리치면 재료가 늘어난다.

## 검증
- `node play/tests/fortress-v9.test.mjs` 규칙 시험(설계도 비용, 놓기 규칙, 1레벨 승패, 고레벨 난이도).
- Playwright(소프트웨어 WebGL, 390×844 터치): 콕 두 번 → 2층, 마우스 끌기 → 한 줄 11칸, 두 손가락 비틀기 → 회전만 하고 블록은 안 놓임, 1레벨 전투 끝까지 진행 후 성공 창.
- 실제 폰 조작감·속도는 아직 확인 못 함.
