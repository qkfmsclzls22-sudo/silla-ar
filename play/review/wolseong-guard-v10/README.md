# 월성 수호대 v10 (뽑기·합치기 디펜스)

주소: `play/?tour=wolseong&mode=guard`

- 금화로 신라 병사를 무작위 소환(일반 75% · 희귀 20% · 영웅 4% · 전설 0.4% · 왕 0.1%).
- 같은 병사 합치기: 일반·희귀 2명, 영웅·전설 3명 → 다음 등급 무작위. 최고 등급은 신라 왕(진흥왕·문무왕·선덕여왕).
- 전설 조합서: 김유신(국선+장군+화랑), 관창(국선+화랑+기마궁수), 원효(천문관+승병+고수).
- 주령구(월지 출토 14면 주사위)를 행운석으로 굴리기, 5웨이브마다 유물 발굴(월성 해자 목간, 얼굴무늬 수막새, 성덕대왕신종, 첨성대, 금관, 토우, 월성 기와, 주령구) 셋 중 하나 고르기.
- 스킬: 해자(6초 동안 적 75% 느리게), 진군 북(8초 공격 속도 +50%).
- 10웨이브마다 보스(60초 안에 처치), 적 100명이 쌓이면 끝. 최고 기록·도감은 폰에 저장.
- 맵: 남산 능선, 첨성대, 계림, 궁궐 전각, 황룡사 구층목탑, 해자와 토성, 성문 누각, 남천과 월정교(밤 풍경).

검증: `node play/tests/guard-v10.test.mjs`, Playwright 터치 시험(콕 눌러 합치기), 자동 플레이 시뮬레이션(보통 33~43웨이브에서 보스에 막힘). 실제 폰 조작감은 확인 전.
