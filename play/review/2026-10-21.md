# 투어별 웹콘텐츠 보강 검토

- 불국사: 공유 마당과 별도로 작동하는 소원 엽서. 이름, 60자 소원, 색깔을 선택하고 1080×1350 PNG를 생성한다. 입력은 이 기기에 저장하며 자동 게시하지 않는다.
- 박물관: 기존 5종의 수집 기록을 유지하고 새 공식 문화유산·복식 7종을 더한 12종 도감. 오답 힌트, 수집 후 이야기, 같은 투어의 포토체험 연결, 1080×1610 도감 저장.
- 월성: 집 3채, 명소 1곳, 자연 3개, 야경 전환의 네 미션. 배치 상태에 따라 완료를 계산하고 1080×1350 건축 기록 카드를 저장한다. 미완성도 저장할 수 있다.
- 모바일: 고정된 3D 화면이 건축 카드 버튼을 가리던 문제를 줄이도록 화면 높이를 조정했다. 높이 650px 이하에서는 고정을 해제한다.

검증 환경: Windows Chrome, 로컬 HTTP 서버, 390×844 모바일 viewport. 실제 휴대폰 검증과 구분한다.

1. 박물관 12개 카드, 반가사유상 오답 힌트 → 정답 수집 → 이야기/포토체험 링크 확인. 새로고침 후 수집 유지. 도감 이미지의 해상도, 12종 배치, 출처 문구 확인.
2. 불국사 별도 QA 마당에서 여행 소원과 파랑 등을 선택해 엽서 생성. 미리보기 해상도와 입력 유지 확인. 공유 마당에 소원을 게시하지 않았다.
3. 월성 기존 기본 배치에서 야경 전환, 기와집 실제 배치로 네 미션 완료 확인. 미완성/완성 두 카드의 제목과 진행률 확인. PNG 다운로드 실제 파일 566,777 bytes 확인. 브라우저 오류 없음.
4. 변경 JavaScript의 node --check 및 git diff --check 통과.

기존 다중 접속 소원 마당의 여러 기기 동시 접속은 이번 변경의 검증 범위에 포함되지 않는다. 새 소원 엽서는 해당 연결과 독립적으로 동작한다.
