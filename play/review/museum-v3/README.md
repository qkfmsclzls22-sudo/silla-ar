새 해설은 국가유산청 자료와 [국립경주박물관 서수모양 주전자](https://gyeongju.museum.go.kr/kor/html/sub04/0402.html?mng_no=44&mode=V), [국립중앙박물관 봉수형 유리병](https://www.museum.go.kr/MUSEUM/contents/M0501000000.do?relicRecommendId=519881&schM=view), [식리총 신발](https://modu.museum.go.kr/explore/video/20699), [국가유산 방문 캠페인 천마도](https://www.kh.or.kr/visit/kor/road/10/view.do?key=2408220010)를 확인해 요약했습니다. 자료만으로 출토품을 특정할 수 없는 목걸이·기마인물형토기 등에는 미확정 소장품 번호를 붙이지 않았습니다. 이미지 생성 도구는 사용하지 않았습니다.
