## 구현과 검증

- Three.js r169 전체 모듈·GLTFLoader·DRACOLoader·OrbitControls·RoomEnvironment를 공식 저장소에서 가져와 로컬 제공. 기존 경량 Three 모듈은 다른 체험용으로 보존. Draco WASM과 라이선스도 로컬 제공.
- 6개 유리 진열장, 실제 GLB 5종, 화면 끌기·확대·진열장 직접 선택, 3가지 해설 탭, 교체·45도 회전·자리 교환·삭제·한 단계 되돌리기.
- 전시 이름·벽 색·배치·개인 감상을 로컬 저장. 외부 전송 없음. 새 기기에 자동 동기화되거나 다른 사람에게 공개되지 않음.
- 모델 캐시 공유, 경량 수막새, DPR 상한 1.6, 장면 변경 시에만 WebGL 렌더, 오류 발생 모델 재시도, WebGL 초기화 실패·컨텍스트 손실 안내.
- 실제 브라우저에서 5종 GLB 렌더를 시각적으로 확인. 빈 진열장에 추가 → 해설 탭 → 회전 → 한 줄 감상 → 자리 교환 → 제목 변경 → 새로고침 유지 → 제거·재배치 → 분위기 변경·되돌리기 → 사진 생성 및 PNG 다운로드 확인.
- 1280×720, 390×844, 320×568 브라우저 뷰포트에서 확인. 390·320px 가로 넘침 없음. 모바일에서는 설명 패널이 열릴 때 3D 화면 자체 높이를 줄여 유물을 가리지 않음. 작은 높이에서는 도입문을 접어 해설 본문을 먼저 표시.
- JavaScript 문법·git 공백 검사 통과. 저장 데이터의 잘못된 ID, 프로토타입 키, 비유한 회전값, 글자 수 제한, 10개 모델·썸네일 경로 검사 통과.
- 초기 구형 경량 Three 모듈의 누락 export를 발견해 별도 전체 r169 모듈로 교체. 초기 모바일 카메라가 천장 밖으로 나가는 문제 수정 후 실내 범위 제한.
- `desktop.jpg`, `mobile.jpg`는 실제 브라우저 캡처. `export.png`는 브라우저의 사진 저장에서 받은 실제 렌더 결과입니다.
- 실제 iOS/Android 기기의 GPU·카메라·네이티브 공유를 테스트한 것은 아닙니다. 이 콘텐츠는 브라우저 전시 체험이며 AR 기능 자체는 변경하지 않았습니다.
