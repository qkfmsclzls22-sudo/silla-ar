## 구현과 검증

- Three.js r169 전체 모듈·GLTFLoader·DRACOLoader·OrbitControls·RoomEnvironment를 공식 저장소에서 가져와 로컬 제공. 기존 경량 Three 모듈은 다른 체험용으로 보존. Draco WASM과 라이선스도 로컬 제공.
- 6개 유리 진열장, 실제 GLB 5종, 화면 끌기·확대·진열장 직접 선택, 3가지 해설 탭, 교체·45도 회전·자리 교환·삭제·한 단계 되돌리기.
- 전시 이름·벽 색·배치·개인 감상을 로컬 저장. 외부 전송 없음. 새 기기에 자동 동기화되거나 다른 사람에게 공개되지 않음.
- 모델 캐시 공유, 경량 수막새, DPR 상한 1.6, 장면 변경 시에만 WebGL 렌더, 오류 발생 모델 재시도, WebGL 초기화 실패·컨텍스트 손실 안내.
- 실제 브라우저에서 5종 GLB 렌더를 시각적으로 확인. 빈 진열장에 추가 → 해설 탭 → 회전 → 한 줄 감상 → 자리 교환 → 제목 변경 → 새로고침 유지 → 제거·재배치 → 분위기 변경·되돌리기 → 사진 생성 및 PNG 다운로드 확인.
- 1280×720, 390×844, 320×568 브라우저 뷰포트에서 확인. 390·320px 가로 넘침 없음. 모바일에서는 설명 패널이 열릴 때 3D 화면 자체 높이를 줄여 유물을 가리지 않음. 작은 높이에서는 도입문을 접어 해설 본문을 먼저 표시.
- JavaScript 문법·git 공백 검사 통과. 저장 데이터의 잘못된 ID, 프로토타입 키, 비유한 회전값, 글자 수 제한, 10개 모델·썸네일 경로 검사 통과.
- 초기 구형 경량 Three 모듈의 누락 export를 발견해 별도 전체 r169 모듈로 교체. 초기 모바일 카메라가 천장 밖으로 나가는 문제 수정 후 실내 범위 제한.
- `desktop.jpg`, `mobile.jpg`는 실제 브라우저 캡처. `export.png`는 브라우저의 사진 저장에서 받은 실제 렌더 결과입니다.
- 실제 iOS/Android 기기의 GPU·카메라·네이티브 공유를 테스트한 것은 아닙니다. 이 콘텐츠는 브라우저 전시 체험이며 AR 기능 자체는 변경하지 않았습니다.

마지막 직접 터치 검사에서 투명한 앞 진열장이 뒤 유물 터치를 가로채는 경우를 발견했습니다. 유물 메시를 먼저 검사하고 불투명한 받침대의 가림은 유지하도록 수정했습니다. 모바일 전체 보기에서 반가사유상 자체를 누르는 흐름을 재검증했습니다.

## 전시 확장 · 2026-10-23

유물 선택지를 5종에서 10종으로 늘리고, 유리 진열장은 6개에서 10개로 확장했습니다. 후면 벽에는 별도의 유리 전시함 4곳을 마련했습니다. 모든 유물을 두 구역 사이로 옮기거나 교환하고 회전할 수 있으며, 회전한 모델의 범위를 다시 계산해 전시함 안에 맞춥니다. 벽면 배치는 체험용 구성으로 실제 박물관의 전시·보존 방식을 재현하지 않습니다.

이번에는 기존에 내려받아 둔 국가유산청 원본을 변환했습니다. 금관 원본의 주변에 분리 배치된 부속품은 전시 파생본에서 제외하고, 조립된 본체 bake_1_cage부터 bake_8_cage까지의 원래 배치와 질감을 유지했습니다. 아미타불의 원본 받침과 스캔 바닥 일부도 유지했습니다. 생성형 이미지와 창작 장식은 추가하지 않았습니다. 자세한 가공 내역은 assets/museum-v4의 각 provenance.json, 변환은 expand_assets.py, 재검증은 check_expansion_models.py에 기록했습니다.

추가 해설은 국립경주박물관 금관총·성덕대왕신종 설명과 국가유산포털 불국사 금동아미타여래좌상 설명을 확인했습니다. 각 유물의 자료·해설 링크와 가공 범위를 화면에서 열 수 있습니다.

- 새 GLB 5개를 Blender에서 다시 불러와 렌더하고 실제 썸네일과 형상을 시각적으로 확인했습니다. render-verification.json에 폴리곤·범위·파일 크기를 기록했습니다.
- 기존 저장 키와 첫 6개 자리의 순서를 유지했습니다. 저장된 제목·배치·회전·감상을 보존하고 새 자리만 확장합니다. 6자리 이전 데이터와 잘못된 ID·회전·긴 감상 입력 정규화 검사를 통과했습니다.
- Chrome의 실제 전시실에서 벽면 2번에 관식 배치 → 45도 회전 → 유리 10번으로 이동 → 벽면으로 복귀 → 새로고침 후 유지 확인. 새 판갑옷을 유리 10번에 배치하고 설명을 열었습니다.
- 390×844 및 320×568 크기의 실제 앱 iframe에서 확인했습니다. 문서 크기는 각각 화면 크기와 같아 페이지 가로·세로 넘침이 없으며, 고정된 조작 바와 설명 하단 버튼을 확인했습니다. 이는 반응형 브라우저 검증이며 실제 휴대폰 GPU 성능 검증은 아닙니다.
